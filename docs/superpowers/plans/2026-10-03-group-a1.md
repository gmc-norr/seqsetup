**Goal:** A multi-index drop never lands on rows the page did not show, a new kit never keeps the old kit's index cycles or read patterns, a LIMS worklist that repeats a sample ID is refused, and the LIMS client's certificate check and size cap are tested (spec `docs/superpowers/specs/2026-10-03-group-a1-design.md`).

- `services/sample_api.py`: `parse_api_samples` refuses a repeated sample ID; `name_list` moves here from the route (spec §3). `_api_get` and the connection classes do not change; new unit tests run them (spec §4).

**Tech Stack:** Python 3.14, FastAPI, HTMX, plain JavaScript, pytest (mongomock in integration tests), Playwright (browser tests), Sphinx.

## Plan-level decisions (spec clarifications; record, do not re-decide)

1. **Rule 2 is a public method, `Sample.drop_kit_settings_without_index()`** (the spec says "a private `Sample` method"). `_apply_kit_defaults` calls it last as well, because an `IndexPair` may have no i5 (`IndexPair.index2` is optional): without that call, a pair kit's `default_index2_cycles` would put i5 cycles on a sample with no i5, the same wrong sheet as review finding F1. For the same reason `assign_index` and `clear_index` call it too (`clear_index` then empties all four, as the spec says). For what was just assigned the method changes nothing, so rule 1 still has the last word there.
2. **`_apply_kit_defaults` refuses an unknown slot** with `ValueError`. Every caller passes a checked value; a typo must not silently skip a setting.
3. **`_name_list` becomes `name_list`** in `services/sample_api.py`, public because two modules use it; its body is unchanged.
4. **The drop check reuses `_parse_sample_ids`**, the route module's existing reader for "a JSON array of strings".
5. **`multiDropTargets` finds the rows once; `multiDropWarning` takes them.** When the drop row is not in `#sample-table` there are no rows: no warning (as today) and `[]` is sent, which the server refuses (it would fill at least the start row). The only other template with drop zones, `wizard/_new_samples_table.html`, is not rendered anywhere.
6. **The Mark Ready test turns the test and application profiles off** with `disable_repos(ctx, "test_profile", "app_profile")`, as `TestInvisibleCharacterStopsMarkReady` does, so it needs no profile setup; `mark_ready()` answers the color-balance question.
7. **The docs screenshot test that drags several indexes runs in a throwaway copy** of the branch: it rewrites a committed picture.
8. **The LIMS client tests patch `ssl.SSLContext.wrap_socket` on the class** (the context is created inside `_api_get`) and `socket.create_connection`. **The size test counts the body bytes the response file hands out**, not the size each read asks for: Python 3.14 reads an unbounded body in growing chunks (`http.client.HTTPResponse._safe_read`, at most doubling each time), so no single read shows it.
9. **The Fill test writes the old kit's settings straight into the stored run**: Fill only fills samples with no index, and after this change clearing an index empties the settings (spec §Tests).
10. **The new integration tests go in one new file**, `tests/integration/test_group_a1.py`.

    """No index, no setting: a sample's index cycles and read patterns go
    when the index they belong to goes (review DI-09; spec 2026-10-03
    group A1, §2, rule 2). Every sample starts with an old kit's four
    settings."""

    I5 = Index(name="i5", sequence="TTGGCCAATT", index_type=IndexType.I5)
    NEW_I7 = Index(name="n7", sequence="CATGCATGCA", index_type=IndexType.I7)
    NEW_I5 = Index(name="n5", sequence="GACTGACTGA", index_type=IndexType.I5)

        return Sample(
            sample_id="S1", index1_cycles=8, index2_cycles=8,
            read1_override_pattern="U8Y*", read2_override_pattern="U8Y*", **indexes,
        )

        return IndexPair(id="p", name="p", index1=self.I7, index2=self.I5 if with_i5 else None)

    @staticmethod
    def _settings(sample):
        return (sample.index1_cycles, sample.index2_cycles,
                sample.read1_override_pattern, sample.read2_override_pattern)

    def test_an_i7_over_a_pair_empties_the_i5_cycles(self):

        assert self._settings(sample) == (8, None, "U8Y*", "U8Y*")

    def test_an_i5_over_a_pair_empties_the_i7_cycles(self):
