> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Six things on main that can put a wrong row, a wrong read or a sheet DRAGEN refuses in front of the lab are refused or written right: a LIMS reply with a name twice, LIMS values of the wrong JSON type, a kit swap that leaves two kits' read patterns on one sample, `IndexOrientation` in a BCLConvert profile, mismatch numbers for an index a sample does not have, and no lane splitting with a Lane column.

**Architecture:** Each rule is checked where its data comes in, and the whole thing is refused rather than guessed: the LIMS reply in `services/sample_api.py`, the kit swap in the three assign routes of `routes/samples.py`, the profile name at sync (`services/sheet_text.py`'s list). The two sheet rules are sheet-plan problems in `services/sheet_plan.py`, so the checks show them and Mark Ready refuses, as for group A3's; the `na` cell is written by `services/samplesheet_v2_exporter.py`.

**Tech Stack:** Python 3, FastAPI, Jinja2, pytest, mongomock, Sphinx.

## Plan-level decisions (spec clarifications; record, do not re-decide)

1. **A repeated name is refused in `_api_get`** by an `object_pairs_hook`, `_refuse_a_repeated_name`, so every LIMS call refuses such a reply at any depth: the connection check, the worklist list and the worklist import. It raises `SampleApiError`, which each caller already shows.
2. **The capitals check runs per row, before the names are lower-cased**, and only for names SeqSetup reads: every alias in `field_aliases`, an admin's mappings included (`read_names`, built once). Names it does not read may come in any spellings.
3. **`fetch_worklist_samples` adds `worksheet_id` only when no name of the row equals it ignoring capitals** (the review of `4d59f3e`): a row with `Worksheet_ID` keeps its own value; a row with iGene's `WorksheetID` (another name once lower-cased) gets it added as today.
4. **`_refuse_a_changed_value` lets text, whole numbers and `None` through** (`None` is how a test that is absent or `null` arrives, `services/sample_api.py`; the review of `4d59f3e`). A `float` gets today's decimal message; `bool` or anything else that is not an `int` gets today's `bool` message, its value shown by `shown_value(json.dumps(value))`.
5. **`parse_api_samples` calls it for every field it reads except the test and the test version**, which keep their own checks after the loop and their group A4 messages. `_FIELD_LABELS` names the fields; an admin's own field is `a value for <field>`. A value that passes is written as `str(val).strip()[:256]`, so a whole number `0` is `"0"`.
6. **The kit swap check is `_kit_swap_refusal(planned)`** in `routes/samples.py`, called in the three assign routes after their own checks and before `saving_run`, with `(sample, slot, kit)` for each sample the request would change. It returns the 400 `Response` (plain text, as the routes' other refusals) or `None`. A request with clashes for more than one kit names the first.
7. **Only an index assigned on its own is kept**: `assign_index1` and `assign_index2` clear the pair, and a pair clears both single indexes (`models/sample.py`), so an i7 assignment keeps `sample.index2` and an i5 assignment keeps `sample.index1`. A pair assignment is never refused. The fill route gives indexes only to samples with none and does not change.
8. **`IndexOrientation` joins `I5_RULE_SETTINGS`**: the sync and the writer's backstop read that one list, in any mix of capitals.
9. **The `na` cell is written by the profile-driven writer only**; the sheet plan's mismatch numbers are not changed (the collision check never compares an index a sample does not have). The fallback writer (`_write_bclconvert_data`, used only when no profile stores are given) does not change (spec §3).
10. **`mismatch_setting_without_index` is found in problem 8's Settings branch** of the sheet plan, one problem per profile and column, after `mismatch_cell_empty`.
11. **`no_lane_splitting_with_lane` is checked for every profile of a BCLConvert section that has a Lane column.** The profile's `NoLaneSplitting`, as the writer would write it (`_settings_text`), wins over the run's, as in the writer; it is on unless it reads `false` or `0`, ignoring capitals.
12. **Allowed changes to existing tests** are listed in each task, with the reason; no other existing test is changed, weakened, skipped or deleted.
