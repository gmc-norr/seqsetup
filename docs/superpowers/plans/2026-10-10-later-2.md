**Goal:** The LIMS worklist import can be used from a draft run's page and is safe: a worksheet whose ID SeqSetup cannot read for sure is left out of the list with a warning, the import reads the worksheet that was picked, a refusal shows in the error banner and leaves the page and the run as they were, and the preview shows exactly what the import would add, or its refusal.

## Plan-level decisions (spec clarifications; record, do not re-decide)

1. **`_worksheet_id(item, config)`** in `services/sample_api.py` reads a worksheet's ID. The names an ID is read from are the admin's worksheet ID field (`config.get_api_field("worksheet_id")`), `worksheet_id` and `id`, lower-cased. Two keys of the item that are one of these once lower-cased raise `ValueError` (the two-spellings message), checked for all three whichever is read. The value is the one `_get_field_value` read: `_raw_field_value(item, field, config)` is that lookup, now shared, and `_get_field_value` returns `str()` of it as before. The worksheet ID field's value is used unless it is `None` or a blank string; then `id`'s. That value goes through `_refuse_a_changed_value` before `str()`.
2. **`fetch_worklists` returns `(success, message, worksheets, left_out)`**; every early return has `[]` as `left_out`. A worksheet left out adds `f"{e} It is left out of the list."`; one with no ID at all is skipped as today, with no warning.
3. **`list_worklists`** passes `warnings` (`{"text": ..., "kind": "warning"}` each) to `wizard/_worklist_selector.html`, which includes `_messages.html` with them above the dropdown; when `success` is false, `_messages_only` shows today's error and then the warnings.
4. **The run page includes the LIMS box with `run_id=run.id`** (`templates/runs/_sample_section.html`).
5. **"Import Samples" targets `#sample-section`** (`outerHTML`); the `add_step1` branch, which has no caller, is unchanged.
6. **The import reads `worklist_id` as `Annotated[str, Form()]`**, as `routes/indexes.py` reads its form fields; `context` stays in the query string.
7. **`_banner_only(request, messages)`** renders `_messages.html` with status 400 and the headers `HX-Retarget: #error-banner`, `HX-Reswap: innerHTML`, `HX-Reselect: unset`, `Cache-Control: no-store` (as `middleware.py`'s `_banner`). Every refusal of `import_worklist_samples` uses it; an import that adds nothing because every sample is already in the run answers as today (200, the section, the warning). Not 200: `static/js/app.js` clears the banner after a 200 from a button whose last request failed, after the swap (review of `5c6ccd2`).
8. **`_plan_worklist_import(run, raw_rows, api_config, worklist_id) -> (new_samples, skipped_ids)`** is the import's loop, moved unchanged: it parses the rows (`parse_api_samples`, looked up at call time), skips sample IDs already in the run, builds each `Sample` as before (lane 1, `worksheet_id` from the row or `worklist_id`, indexes, kit name, Override Cycles) and raises `ValueError` for the parser's refusals and the run's maximum. It changes nothing. The import shows `Worklist import rejected: <e>` and `No valid samples found in worklist.` when the plan has no rows at all, as before.
9. **`preview_worklist` takes `get_editable_run`** (a draft only, 403 otherwise) and shows the plan: every sample, no row limit.
10. **Allowed changes to existing tests** are listed in Task 2, with the reason; no other existing test is changed, weakened, skipped or deleted.

"""The worksheet list's IDs: an ID that is not text or a whole number, or that
comes under two spellings of one name, leaves that worksheet out of the list
with a warning; the other worksheets are listed as today (spec 2026-10-10
later list slice 2, §3). The LIMS reply goes through the real _api_get."""

import pytest

from seqsetup.models.sample_api_config import SampleApiConfig
from seqsetup.services.sample_api import fetch_worklists

from .test_sample_api import lims_wire  # noqa: F401 - a fixture

CONFIG = SampleApiConfig(base_url="https://lims.example.org/api", enabled=True)
MAPPED = SampleApiConfig(base_url="https://lims.example.org/api", enabled=True,
                         field_mappings={"worksheet_id": "AL"})

DECIMAL = ('A worksheet in the LIMS list has an ID that is a number with a decimal point (25.1), '
           'which JSON may have changed (1.10 is read as 1.1). Send it as text, for example '
           '"1.10". It is left out of the list.')


def _not_text(shown):
    return (f"A worksheet in the LIMS list has an ID that is not text or a whole number "
            f"({shown}). It is left out of the list.")


def _two(a, b):
    return (f"A worksheet in the LIMS list has the names {a!r} and {b!r}, which SeqSetup reads "
            f"as one name. Send only one of them. It is left out of the list.")


def _listed(wire, body, config=CONFIG):
    wire.body = body
    ok, message, worksheets, left_out = fetch_worklists(config)
    return ok, message, [w["id"] for w in worksheets], left_out


class TestAnIdOfTheWrongTypeIsLeftOut:
    """str() would read JSON 25.10 as "25.1" and true as "True", and the
    import would then fetch that other ID."""

    def test_a_decimal_number(self, lims_wire):
        assert _listed(lims_wire, b'[{"id": "W1"}, {"id": 25.10}]') == (
            True, "Found 1 worksheets", ["W1"], [DECIMAL])

    @pytest.mark.parametrize("raw, shown", [
        (b"true", "true"), (b"false", "false"), (b'["a"]', '["a"]'), (b'{"a": 1}', '{"a": 1}'),
    ])
    def test_not_text_or_a_whole_number(self, lims_wire, raw, shown):
        body = b'[{"id": "W1"}, {"id": ' + raw + b'}]'
        assert _listed(lims_wire, body) == (True, "Found 1 worksheets", ["W1"], [_not_text(shown)])


class TestTextAndWholeNumbersAreListedAsToday:

    def test_text_and_whole_numbers(self, lims_wire):
        assert _listed(lims_wire, b'[{"id": "25.10"}, {"id": 7}, {"id": 0}, {"id": " W2 "}]') == (
            True, "Found 4 worksheets", ["25.10", "7", "0", "W2"], [])

    def test_a_worksheet_without_an_id_is_not_listed_as_today(self, lims_wire):
        assert _listed(lims_wire, b'[{"id": "W1"}, {"name": "no id"}, {"id": null}]') == (
            True, "Found 1 worksheets", ["W1"], [])


class TestTheIdFallback:
    """The ID is the worksheet ID field, or id when that is absent, null or
    blank; the one read is the one checked."""

    def test_id_is_read_when_the_worksheet_id_is_absent(self, lims_wire):
        assert _listed(lims_wire, b'[{"name": "n", "id": 25.10}]') == (
            False, "No valid worksheets found in API response", [], [DECIMAL])

    def test_id_is_read_when_the_worksheet_id_is_null_or_blank(self, lims_wire):
        body = b'[{"worksheet_id": null, "id": "W1"}, {"worksheet_id": " ", "id": true}]'
        assert _listed(lims_wire, body) == (True, "Found 1 worksheets", ["W1"], [_not_text("true")])

    def test_the_worksheet_id_wins_over_id(self, lims_wire):
        assert _listed(lims_wire, b'[{"worksheet_id": "W1", "id": 2.5}]') == (
            True, "Found 1 worksheets", ["W1"], [])


class TestAnAdminsWorksheetIdField:

    def test_the_mapped_field_is_the_one_checked(self, lims_wire):
        assert _listed(lims_wire, b'[{"AL": 25.10, "id": "W1"}, {"AL": "W2"}]', MAPPED) == (
            True, "Found 1 worksheets", ["W2"], [DECIMAL])


class TestTwoSpellingsOfAnIdName:
    """Lower-cased, the last spelling won, with no warning. Both values pass
    a type check, and slice 1's check catches only the same name twice."""

    def test_worksheet_id_in_two_spellings(self, lims_wire):
        body = b'[{"Worksheet_ID": "W_A", "WORKSHEET_ID": "W_B"}, {"id": "W1"}]'
        assert _listed(lims_wire, body) == (
            True, "Found 1 worksheets", ["W1"], [_two("Worksheet_ID", "WORKSHEET_ID")])

    def test_a_mapped_name_in_two_spellings(self, lims_wire):
        body = b'[{"Al": "W_A", "al": "W_B"}, {"AL": "W1"}]'
        assert _listed(lims_wire, body, MAPPED) == (
            True, "Found 1 worksheets", ["W1"], [_two("Al", "al")])

    def test_id_in_two_spellings(self, lims_wire):
        assert _listed(lims_wire, b'[{"Id": "W_A", "ID": "W_B"}]') == (
            False, "No valid worksheets found in API response", [], [_two("Id", "ID")])

    def test_id_in_two_spellings_is_refused_also_when_the_worksheet_id_is_read(self, lims_wire):
        body = b'[{"worksheet_id": "W1", "Id": "a", "ID": "b"}]'
        assert _listed(lims_wire, body) == (
            False, "No valid worksheets found in API response", [], [_two("Id", "ID")])

    def test_other_names_may_come_in_two_spellings(self, lims_wire):
        body = b'[{"id": "W1", "Name": "a", "NAME": "b"}]'
        assert _listed(lims_wire, body)[2] == ["W1"]

"""Later list, slice 2: the LIMS import works from the run page, a worksheet
whose ID SeqSetup cannot read for sure is left out of the list, and the
preview shows what the import would add (spec 2026-10-10 later list slice 2)."""

from markupsafe import escape

from seqsetup.models.sample import Sample
from seqsetup.models.sample_api_config import SampleApiConfig
from seqsetup.models.sequencing_run import InstrumentPlatform, RunCycles, SequencingRun
from seqsetup.services import sample_api as sample_api_module

ORIGIN = {"Origin": "http://testserver"}
RUN = "l2-run"


def _run(ctx, sample_ids=()):
    """Save a NovaSeq X draft with one sample per Sample ID given."""
    run = SequencingRun(
        id=RUN, run_name="L2", instrument_platform=InstrumentPlatform.NOVASEQ_X,
        flowcell_type="10B", run_cycles=RunCycles(151, 151, 10, 10),
    )
    for k, sample_id in enumerate(sample_ids, start=1):
        run.add_sample(Sample(id=f"s{k}", sample_id=sample_id, lanes=[1]))
    ctx.run_repo.save(run)


def _lims_on(ctx, mappings=None):
    ctx.sample_api_config_repo.save(SampleApiConfig(
        base_url="https://lims.example.org/api", enabled=True, field_mappings=mappings or {}))


def _worksheet_list(monkeypatch, items):
    """The LIMS's worksheet list, with no network; fetch_worklists runs."""
    monkeypatch.setattr(sample_api_module, "_api_get", lambda url, api_key="": items)


def _options(html):
    return re.findall(r'<option value="([^"]*)"', html)


# --- spec §3: worksheet IDs --------------------------------------------------

LEFT_OUT = ('A worksheet in the LIMS list has an ID that is a number with a decimal point (25.1), '
            'which JSON may have changed (1.10 is read as 1.1). Send it as text, for example '
            '"1.10". It is left out of the list.')

        _app, ctx, _db = fresh_app
        _run(ctx)

def git_clean() -> bool:
    return subprocess.run(["git", "diff", "--quiet"]).returncode == 0


def main():
    if sys.argv[1:] == ["--check"]:
        bad = []
        for number, (path, old, new, tests) in enumerate(MUTATIONS, start=1):
            n = Path(path).read_text().count(old)
            if n != 1 or old == new:
                bad.append((number, path, n))
        print(f"{len(MUTATIONS)} mutations; Find not matching once: {bad or 'none'}")
        return
    first = int(sys.argv[1]) if len(sys.argv) > 1 else 1
    last = int(sys.argv[2]) if len(sys.argv) > 2 else len(MUTATIONS)
    assert git_clean(), "tree is not clean"
    env = {**os.environ, "PYTHONPATH": "src", "PYTHONDONTWRITEBYTECODE": "1",
           "MONGODB_URI": "mongodb://127.0.0.1:1"}
    results = []
    for number, (path, old, new, tests) in enumerate(MUTATIONS, start=1):
        if number < first or number > last:
            continue
        p = Path(path)
        original = p.read_text()
        assert original.count(old) == 1, f"#{number}: Find matches {original.count(old)} times"
        mutated = original.replace(old, new)
        assert mutated != original
        p.write_text(mutated)
        try:
            proc = subprocess.run(
                [PY, "-m", "pytest", *tests, "-q", "-p", "no:cacheprovider", "--no-header"],
                env=env, capture_output=True, text=True, timeout=900,
            )
            tail = [l for l in proc.stdout.splitlines() if " passed" in l or " failed" in l or "error" in l]
            summary = tail[-1] if tail else proc.stdout[-200:]
            failed = " failed" in summary
            broken = "error" in summary and not failed
        finally:
            p.write_text(original)
        assert git_clean(), f"#{number}: tree not clean after restore"
        verdict = "RED" if failed else ("BROKEN" if broken else "GREEN (BAD)")
        results.append((number, verdict))
        print(f"#{number}: {verdict} -- {summary}", flush=True)
    bad = [n for n, verdict in results if verdict != "RED"]
    print("all red" if not bad else f"not red: {bad}")
