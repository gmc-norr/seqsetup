File format help

YAML: structured with kit_name, kit_version, index_mode, indexes or index_pairs sections.

CSV/TSV: header row with columns like name, sequence (single) or name, i7_sequence, i5_sequence (dual) or i7_name, i7_sequence, i5_name, i5_sequence (combinatorial).

See the project documentation for examples.

Override cycles help

Index/read override patterns control how many cycles the sequencer dedicates to each read.

I8 = use 8 index cycles. I* (or blank) = use the actual sequence length.

Y150 = 150 read cycles. Y* (or blank) = use the run's default.
