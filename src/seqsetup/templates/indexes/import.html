File format help

YAML: SeqSetup's own format, as Download YAML writes it (name, version, then index_pairs or i7_indexes / i5_indexes; the Index mode picked above is used, not the file's index_mode, which must still be one of the three), or Illumina's (Name, Version, IndexSequences with i7Index1 and i5Index2; quote a name made only of digits, such as '012').

CSV: a header row name,index,index2, one pair per row (leave out index2 for Single); or, for Combinatorial, an [i7] and an [i5] section (in lower case), each with name,sequence.

TSV: Illumina's [IndexKit] and [Indices] sections, separated by tabs; each index line is its name, its sequence, and 1 (i7) or 2 (i5).

In Unique Dual mode, an Illumina YAML or TSV file's i7 and i5 are paired only when they have the same name. A file whose names do not pair up is refused, naming them: upload it as Combinatorial, or as a CSV with each pair on one row. A name given twice in one list is refused too; spaces around a name do not make it another name. SeqSetup cannot tell a combinatorial kit whose i7 and i5 happen to share names from one of fixed pairs: pick the mode the kit really is.

The whole file is refused, and nothing is saved, when it carries i5 data and Single is picked (a Single kit saves the i7 indexes only); when a CSV row has content but no name or no i7 sequence, has more cells than the header or a cell in a column with no name, or is in no section of an [i7]/[i5] file; when a TSV [Indices] line is not a name, a sequence and 1 or 2 — the refusal names the lines; when a CSV column's name still looks like an index or a lane after lower case, spaces and underscores are taken out but names no column of the format (Lane, Barcode, I7_Index_ID), or when two columns name one of them; when a TSV line is in no section or under a marker the format does not read ([Indexes]); when the index list in a SeqSetup-format file is not one the chosen mode reads; when an Illumina YAML gives both i7Index1 and Index1, or both i5Index2 and Index2, for one list; or when a key or an index name is given twice. A TSV's [IndexKit] keys other than Name, Version and Description are not read — check the kit's detail page after uploading one.

Override cycles help

Index/read override patterns control how many cycles the sequencer dedicates to each read.

I8 = use 8 index cycles. I* (or blank) = use the actual sequence length.

Y150 = 150 read cycles. Y* (or blank) = use the run's default.
