Paste Format Help
Basic

sample_id and test_id columns. Tab or comma-separated.

sample_id	test_id
Sample001	WGS
Sample002	RNA
Sample003	WGS

A header row is auto-detected and used for column mapping. Without a header, only two columns are read: sample_id, then test_id. Index and name columns need a header row.

With Test Versions

A test_version column: 1 means the newest 1.x.x, 1.2 the newest 1.2.x, 1.2.3 exactly that one. Needs a header row.

sample_id	test_id	test_version
Sample001	WGS	1
Sample002	RNA	2.1
With Indexes

Include index_i7 and/or index_i5 sequences to auto-assign indexes on paste. Needs a header row. A column that looks like an index or a lane but is not one of these names (for example "Index 2" or "Lane") refuses the paste.

sample_id	test_id	index_i7	index_i5
Sample001	WGS	ATTACTCG	TATAGCCT
Sample002	RNA	TCCGGAGA	ATAGAGGC
Sample003	WGS	CGCTCATT	CCTATCCT
With Index Names

Optionally include index_pair_name, i7_name, and i5_name columns.

sample_id	test_id	index_i7	index_i5	index_pair_name	i7_name	i5_name
Sample001	WGS	ATTACTCG	TATAGCCT	UDP0001	D701	D501
Sample002	RNA	TCCGGAGA	ATAGAGGC	UDP0002	D702	D502

All name columns are optional. Without names, sequences are used as index names and 'Pasted' as the kit name.

Minimal

Single column with just sample_ids.

Sample001
Sample002
Sample003
