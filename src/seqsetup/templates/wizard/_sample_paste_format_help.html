Paste Format Help
Basic

sample_id and test_id columns. Tab or comma-separated.

sample_id	test_id
Sample001	WGS
Sample002	RNA
Sample003	WGS

A header row is auto-detected and used for column mapping. Without a header, columns default to: sample_id, test_id, index_i7, index_i5. Name columns require a header row.

With Indexes

Include index_i7 and/or index_i5 sequences to auto-assign indexes on paste.

sample_id	test_id	index_i7	index_i5
Sample001	WGS	ATTACTCG	TATAGCCT
Sample002	RNA	TCCGGAGA	ATAGAGGC
Sample003	WGS	CGCTCATT	CCTATCCT
With Index Names

Optionally include index_pair_name, i7_name, and i5_name columns.

sample_id	test_id	index_i7	index_i5	index_pair_name	i7_name	i5_name
Sample001	WGS	ATTACTCG	TATAGCCT	UDP0001	D701	D501
Sample002	RNA	TCCGGAGA	ATAGAGGC	UDP0002	D702	D502

All name columns are optional. Without names, sequences are used as index names and 'Pasted' as the kit name.
